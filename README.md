## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/ritesh-singh/portfolio.git
cd portfolio
```

2. **Install dependencies:**

```bash
npm install
```

3. **Add your professional image:**

```bash
# Place your professional headshot at:
public/my-image.jpg
```

4. **Customize your information:**
   Edit the components in `src/components/` to add your:

- Bio and professional summary
- Project details and links
- Experience details
- Education information
- Contact information

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## 📝 Customization Guide

### Update Hero Section

Edit `src/components/HeroSection.tsx`:

- Change the headshot image path
- Update bio text
- Modify call-to-action links

### Update Projects

Edit `src/components/ProjectShowcase.tsx`:

- Add your project details
- Update live links and demo URLs
- Modify technologies list

### Update Experience

Edit `src/components/Experience.tsx`:

- Add your work experiences
- Update company names and roles
- Modify responsibilities and achievements

### Update Skills

Edit `src/components/TechnicalStack.tsx`:

- Add/remove technology categories
- Update technology lists
- Customize color schemes

### Update Contact

Edit `src/components/EducationContact.tsx`:

- Update education details (college, CGPA, graduation date)
- Modify contact information
- Update social media links

### Customize Colors

Edit `tailwind.config.ts` to change:

- Primary colors (emerald green, cyan)
- Background colors
- Border colors
- Custom animations
